# Recursos visuales

Generados con la herramienta integrada `image_gen` para este proyecto. Se guardan en `public/images/` como WebP de 640, 1280 y 1920 px. No se han utilizado fotografías de empresas ajenas. Las imágenes y esquemas son ilustrativos y se etiquetan como tales. El logotipo y los esquemas SVG se crearon como recursos vectoriales propios.

La fuente Manrope se sirve localmente. Fuente original: https://github.com/google/fonts/tree/main/ofl/manrope. Licencia OFL incluida en `public/fonts/OFL-Manrope.txt`.
